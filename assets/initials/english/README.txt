Coptic Vine English initials (A-Z)
Old English capitals: Roman skeletons written in UnifrakturMaguntia's pen,
built from Maguntia's own stem, swash bar and terminals. One colour.

initials/initial_A.svg ... initial_Z.svg
  One path each, class="initial-letter" (green #5FAE68 in the annual palette).
  Recolour per season with CSS fill on .initial-letter.
  viewBox height is 1699 units for every letter, so all letters share one scale:
  the cap height is 1440 units (y = -1440 to 0); flourishes reach 92 above
  and 167 below. Widths vary by letter.
